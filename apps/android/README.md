# AniMori для Android

Клиент AniList для Android 7.0+ с сенсорным интерфейсом. Стек: Vue 3, TypeScript-ядро без DOM, Tauri 2 и Rust-оболочка.

Приложение содержит календарь, рекомендации, списки, поиск, карточки тайтлов, историю просмотра и HLS-плеер. Списки и настройки хранятся локально; поддерживаются импорт из AniList, Шикимори и XML MyAnimeList, экспорт XML и облачная копия на Яндекс Диске. Русские названия загружаются из Shikimori и датасета `animori-data`.

Исходный код: `apps/android`. Общее ядро: `packages/core`. Архитектура и хранение описаны в [docs/dev/android](../../docs/dev/android).
