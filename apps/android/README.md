# AniMori — приложение для телефона

Клиент AniList для телефонов на Android 7.0 и новее, управление пальцем.
Оболочка — Tauri 2 (Rust), интерфейс — Vue 3, общее ядро — TypeScript без DOM.
Проект неофициальный и с командой AniList не связан.

Каталог — `apps/android` в общем репозитории `foulnike/Animori`.

## Команды

```bash
npm run dev:app         # интерфейс в браузере, без оболочки
npm run build:app       # проверка типов и сборка интерфейса в dist/app
npm run typecheck:all   # ядро отдельно, затем всё вместе
npm test                # vitest, проверки чистых модулей ядра
npm run tauri -- android dev            # запуск на подключённом устройстве
npm run tauri -- android build -t arm64 # APK
```

## Отладка на устройстве

Телефон по USB, включённая отладка по USB. Перед запуском — туннель
dev-сервера:

```bash
adb reverse tcp:1430 tcp:1430
npm run tauri -- android dev --host 127.0.0.1
```

1430 — порт dev-сервера Tauri; `--host 127.0.0.1` обязателен, иначе оболочка
привязывается к адресу, которого телефон по кабелю не видит. Горячей
подстановки нет: правки доходят перезапуском сессии.
