# AniMori для Windows

Настольный клиент AniList для Windows 10/11. Стек: Vue 3, TypeScript-ядро без DOM, Tauri 2 и Rust-оболочка.

Приложение содержит календарь, рекомендации, списки, статистику, поиск, карточки тайтлов, студии, историю и встроенный HLS-плеер. Доступны полноэкранный режим, отдельное окно просмотра и системная панель трансляции. Списки хранятся локально; импорт выполняется из AniList, Шикимори или XML MyAnimeList, экспорт — в XML или облачную копию на Яндекс Диск. Русские названия поступают из Shikimori и датасета `animori-data`; описания — из Shikimori.

Исходный код: `apps/windows`. Общее ядро: `packages/core`. Архитектура и хранение описаны в [docs/dev/windows](../../docs/dev/windows). Канал обновлений Tauri использует `windows-latest`.
