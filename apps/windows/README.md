# AniMori — приложение для AniList

**Настольный клиент [AniList](https://anilist.co) для Windows со своим интерфейсом: списки, поиск, страницы с названиями и студий, встроенный плеер. Всё на русском, без браузера и менеджера скриптов.**

**AniMori** — отдельная программа, которая работает с AniList напрямую. Она сама загружает данные, сама отрисовывает экраны и подставляет русские названия и описания из Shikimori.

AniMori — неофициальный проект, он не связан с командой AniList.

> [!NOTE]
> **Что где лежит.** Продукт один — [AniMori](https://github.com/foulnike/Animori), и всё
> в этом репозитории: общее ядро в `packages/core`, настольное приложение в
> `apps/windows`, приставка в `apps/android-tv`, телефон в `apps/android`. Ветка одна — `main`.<br>
> Юзерскрипт и прежний репозиторий приставки убраны в архив: история и выпуски на месте,
> кода в них больше нет.

## Состояние

Текущая версия — 3.1.2. В разделе [Releases](https://github.com/foulnike/Animori/releases) есть установщик, портативный архив и манифест обновлений.

> [!IMPORTANT]
> **Портативному архиву нужен WebView2 Runtime.** Установщик тянет его сам, а
> портативный `AniMori_*_x64-portable.zip` — нет: распакуйте архив и запустите
> `AniMori.exe`. Если окно не открывается, поставьте Runtime
> ([официальная страница](https://developer.microsoft.com/microsoft-edge/webview2/))
> и повторите. Windows 11 и свежие обновления Windows 10 включают его в систему.

Гибридная версия 2.0.2 больше не поддерживается и удалена из рабочих веток. Установленные копии обновились до 3.0 автоматически: идентификатор программы (`com.foulnike.animori`), ключ подписи и адрес манифеста обновлений не изменились. Настройки и токен хранятся в том же профиле, новая версия их подхватывает. Подробнее — в [`docs/dev/windows/ARCHITECTURE.md`](../../docs/dev/windows/ARCHITECTURE.md).

## Что оно может

**Смотреть.** Встроенный плеер с выбором серии, озвучки и качества, два источника
— Aniliberty и Kodik. Видео можно вынести в маленькое окно поверх других программ
или транслировать на телевизор. История помнит, где вы остановились: «Продолжить»
в один клик, стирание рядом — в два нажатия.

**Вести список.** Список живёт на устройстве и открывается мгновенно, без сети.
Запись правится прямо в шторке: статус, оценка, число серий, пересмотры, даты,
заметка. Свой список можно взять из AniList, с Шикимори по нику или файлом
выгрузки MyAnimeList — слиянием или заменой, как вам удобнее. Экспорт — в тот же XML,
который принимают Шикимори, AniList и Kitsu, или копия в облако.
Изменения остаются у вас: на AniList и Шикимори приложение их не отправляет.

**Знать о тайтле.** Карточка с русским описанием и названиями, персонажами и
авторами с русскими именами, студией на отдельном экране, кадрами, трейлером,
опенингами и эндингами. На главной — календарь выхода серий и календарик
активности за год: квадрат — день, тон — сколько в нём было дел, щелчок открывает
день по тайтлам. Журнал активности пишется с версии 3.0.3, поэтому первый год
пустой.

**Считать и искать.** Статистика по своей коллекции: общее время просмотра,
серии, завершённые тайтлы, своя оценка против оценки сообщества, кольца по
статусам и форматам, столбики оценок и гистограмма по годам с переключением
метрик. Поиск — по названиям, персонажам и авторам, на русском.

**Настроить под себя.** Три темы и свой акцент, источник русских названий, прокси
для AniList с живой проверкой, вход в AniList, взрослое содержимое одним
тумблером, журнал отладки с отбором и копированием в буфер, «Стереть историю».

Разделы — **Главная**, **Моё**, **Статистика**, **История**, **Поиск** и
**Настройки**; из них открываются **Аниме**, **Студия** и **Просмотр**.

Запросы к API идут из процесса приложения, а не из веб-части: ограничения
браузера не мешают, заголовки запросов под контролем. Внешние ссылки открываются
в браузере системы, полноэкранный режим включается клавишей `F`. Токен, настройки
и кэш остаются на компьютере. Приложение ведёт только аниме, рисует экраны само и
обновляется вместе с подписью пакета.

Как устроено — [`docs/dev/windows/ARCHITECTURE.md`](../../docs/dev/windows/ARCHITECTURE.md), где живут данные —
[`docs/dev/windows/STORAGE.md`](../../docs/dev/windows/STORAGE.md).

## Требования

Windows 10 или 11 и компонент **WebView2**. В Windows 11 и обновлённой Windows 10 он уже установлен. Если его нет, установщик предложит его скачать.

## Сборка из исходников

Нужны Node.js и [окружение Rust и Tauri](https://tauri.app/start/prerequisites/).

```bash
npm install
npm run dev:app        # фронтенд в браузере
npm run tauri:dev      # приложение в окне
npm run build:app      # сборка фронтенда → dist/app
npm run tauri:build    # установщики NSIS и MSI → src-tauri/target/release/bundle/
npm run typecheck:all  # проверка типов: сначала ядро отдельно, затем весь проект
npm test               # тесты с заглушкой вместо моста, Tauri не нужен
```

`npm run tauri:build` подписывает пакет обновления, поэтому ему нужны переменные окружения `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Свою пару ключей можно создать командой `npm run tauri signer generate`.

Код разделён на слои: `packages/core/src/` — ядро (API, данные, кэш, мост к платформе), `src/app/` — экраны, компоненты и роутер, `src-tauri/` — нативная часть на Rust. Ядро ничего не знает об остальном приложении. Это проверяет `npm run typecheck:shared`: он собирает ядро без каталога `src/app` и падает, если ядро что-то импортирует оттуда.

## Выпуск

Релиз запускается тегом вида `windows-v3.1.2`. Сборка на `windows-latest` сверяет номер версии в теге с `package.json`, компилирует Rust, собирает установщик, подписывает обновление и публикует рядом `latest.json`. Описание релиза берётся из верхнего раздела `CHANGELOG.md`.

## Источники данных

| Источник | Для чего |
| :--- | :--- |
| `graphql.anilist.co` | данные и списки AniList |
| `shikimori.rip`, `shikimori.io` | русские названия, описания, персонажи, франшизы (зеркала одного сервиса, опрашиваются по очереди) |
| `anilibria.top`, `kodik-api.com` | прямые ссылки на видео для встроенного плеера |
| `graphql.animethemes.moe` | опенинги и эндинги |
| `cloud-api.yandex.net` | облачная копия списка: только по кнопке и только с вашей авторизацией |
| `github.com` | манифест обновлений и готовые данные (`foulnike/animori-data`) |

Все запросы отправляет сама программа. Ваши данные не передаются на сторонние серверы: токен и настройки остаются на вашем компьютере, кэш тоже локальный. Облачная копия сохраняется только на ваш собственный диск и только когда вы нажмёте кнопку. Как собираются готовые данные — в [`docs/dev/windows/STORAGE.md`](../../docs/dev/windows/STORAGE.md).
