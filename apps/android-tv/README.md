# AniMori для Android TV

Клиент AniList для Android TV 7.0+ с управлением пультом. Стек: Vue 3, TypeScript-ядро без DOM, Tauri 2 и Rust-оболочка.

Приложение содержит календарь, рекомендации, локальные списки, поиск, карточки тайтлов, историю и HLS-плеер. В плеере доступны источники Anilibria и Kodik. Запись списка изменяется локально; поддерживается импорт списка из Шикимори и восстановление копии с Яндекс Диска. Русские названия поступают из Shikimori и датасета `animori-data`.

Основные разделы интерфейса: **Главная**, **Моё**, **История**, **Поиск**, **Настройки**. Карточка тайтла содержит описание, персонажей, персонал, студию, кадры, трейлер и музыкальные темы.

Исходный код: `apps/android-tv`. Общее ядро: `packages/core`. Архитектура и хранение описаны в [docs/dev/android-tv](../../docs/dev/android-tv).
