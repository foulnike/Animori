# Документация AniMori для приставки

Клиент AniList со своим интерфейсом под Android TV. Оболочка — Tauri 2 (Rust), интерфейс — Vue 3, общее ядро — TypeScript без DOM.

| Файл | О чём |
| --- | --- |
| `ARCHITECTURE.md` | слои, ядро, мост, экраны, вход, обновление, источники данных |
| `STORAGE.md` | настройки, снимок, склад, датасет, облако, выгрузка |
| `CONVENTIONS.md` | правила кода и документации |

Репозиторий один — `foulnike/Animori`, ветка `main`. Общее с настольной сборкой ядро лежит в `packages/core`; правило границы — в `CONVENTIONS.md`.

Описание продукта и порядок установки — в `README.md` в корне репозитория.

## Команды

```bash
npm run dev:app         # интерфейс в браузере, без оболочки
npm run build:app       # проверка типов и сборка интерфейса в dist/app
npm run typecheck:all   # ядро отдельно, затем всё вместе
npm test                # vitest, проверки чистых модулей ядра
npm run tauri:build     # сборка оболочки под текущую платформу
```

`tauri:dev` пересобирает интерфейс целиком: горячей подстановки нет.
