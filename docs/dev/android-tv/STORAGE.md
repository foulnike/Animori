# Хранение Android TV

## Настройки и снимок

`core/settings.ts` хранит настройки интерфейса, фильтрации, прокси и облака через `Bridge.storage`. `core/store-chain.ts` сериализует записи.

`core/snapshot.ts` сохраняет локальный список. Файловый дубль `animori-snapshot.json` находится в приватном каталоге оболочки; допустимые имена определяет `src-tauri/src/files.rs`.

AniList используется как источник данных. Импорт списка выполняется из Shikimori или из облачной копии; локальные правки сохраняются на устройстве.

## Кэш и датасет

`core/db.ts` хранит кэш карточек и вспомогательных ответов в IndexedDB. `core/dataset-names.ts` использует файлы `animori-data` с русскими названиями и картой MAL/AniList. Сжатый датасет проверяется по описанию и SHA-256, затем сохраняется как `animori-dataset.json`.

Порядок разрешения названий: память, датасет, IndexedDB, API Shikimori. Сроки кэша заданы `core/cache-life.ts`.

## Облако и секреты

Яндекс Диск реализован в `src-tauri/src/cloud.rs`; копия списка создаётся и восстанавливается по действию пользователя. Токен облака, AniList и пароль прокси шифруются Android Keystore и обрабатываются Rust/Kotlin-слоем. WebView получает только статус и результаты операций.
