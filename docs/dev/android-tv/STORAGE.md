# Хранение

## Настройки

`core/settings.ts`. Читать `settings.x` в момент использования, а не копировать
при загрузке. До `await loadSettings()` в модуле лежат дефолты, а импорты
выполняются до `start()` в `app/main.ts`.

Логировать из модуля можно: журнал настроек не читает, иначе был бы цикл.

## Хранилище моста

`Bridge.storage`. Хранилище моста про транзакции не знает, поэтому записи
выстраиваются цепочкой — `core/store-chain.ts`: идущая запись держит следующую
за собой. Порядок один на всех писателей.

## Снимок

`core/snapshot.ts` — то из данных пользователя, что потерять нельзя. Склад
ответов сети (`db.ts`) в него не входит.

Базы приложения нет: источник правды — массив в памяти, на диске одна запись.
Плюс дубль файлом через `files.rs`. Имя файла — только из списка в `files.rs`,
каталог только приватный.

## Склад

`core/db.ts`, IndexedDB: карточки (`mediaCache`), соответствия MAL, франшизы.
Инстанс базы приватен; через мост прятать не нужно.

Здесь же лежат ответы о доступности видео. Сроки — `core/cache-life.ts`.

## Датасет названий

Файлы выпуска на диске, читаются без сети: `core/dataset-names.ts` между
памятью и складом. Подробности обновления — в `ARCHITECTURE.md`.

## Облако

Яндекс Диск. Копия лежит в папке приложения (`app:`, область
`disk.app_folder`): корня Диска пропуск не видит. Своего пропуска приставка не
вводит — поля ввода токена нет, `am_cloud_token` остаётся пустым; копию только
читают по опубликованной ссылке (`linkInfo`/`pullByLink`), и та пропуска не
требует.

Облако читает только по действию человека. Формат копии —
`core/cloud-file.ts`, модуль чистый: список покидает машину только здесь.
Провайдер один.

Файл настроек `animori-settings.json` открыт: `auth_token` и `set_proxy_pass`
лежат в нём открытым текстом. `CLOSED_KEYS` (`storage.rs`) запрещает читать
`auth_token` только из окна через `animori_storage_read` — это не шифрование.
Кражу файла с диска закрывает лишь шифрование хранилища (OS keyring; отложено);
риск принят.

## Выгрузка списка

Выгрузки списка на приставке нет: формат обмена (`core/mal-xml.ts`, XML экспорта
MyAnimeList) зовёт только настольное приложение. Команды выгрузки в оболочке
присутствуют — это общий код, интерфейс их не использует.

## Список односторонний

Правки хранятся только в памяти коллекции и на сервер не уезжают. Перенос по
умолчанию сливает, а не замещает. Источник переноса один — Шикимори по нику:
перенос с AniList требует входа, которого на приставке нет.
