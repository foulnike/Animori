# Хранение приложения Windows

## Список и снимок

`core/collection.ts` хранит локальный список в памяти. `editEntry()` изменяет запись и сохраняет снимок; AniList используется как источник импорта. Поддерживаются импорт из AniList, Shikimori и XML MyAnimeList, слияние и замена.

`core/snapshot.ts` записывает список и пользовательские поля под ключом `AM_SNAPSHOT`. Состояние просмотра хранится модулем плеера отдельно. Файловый дубль `animori-snapshot.json` создаётся в приватном каталоге Rust-оболочки. `core/activity.ts` отдельно хранит журнал изменений активности.

## Кэш и датасет

`core/db.ts` хранит ответы API в IndexedDB с ограничениями срока из `core/cache-life.ts`. Русские названия разрешаются из памяти, локального датасета, IndexedDB и API Shikimori.

`core/dataset-names.ts` загружает из `animori-data` файлы `index.json`, `titles-anime.json.gz` и `map-mal-anilist.json.gz`, проверяет SHA-256 и сохраняет распакованный `animori-dataset.json` через файловый мост.

## XML и облако

`core/mal-xml.ts` формирует XML формата MyAnimeList. `src/app/save-file.ts` сохраняет его через системный выбор каталога; экспорт не использует служебное файловое хранилище.

Облачная копия реализована в `core/cloud.ts` и `api/yandex-disk.ts`. Файл хранится в каталоге приложения Яндекс Диска, а операции выполняются по действию пользователя. Поддерживаются создание, восстановление, публикация и чтение по публичной ссылке.

## Секреты

AniList token, токен Яндекс Диска и пароль прокси доступны только Rust-слою `src-tauri/src/secrets.rs`. Интерфейс получает статусы и результаты операций без самих секретов.
