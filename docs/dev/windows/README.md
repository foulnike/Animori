# Документация приложения

Здесь только про десктопное приложение AniMori.

Общее с приставкой ядро лежит в `packages/core`, её документация — в
`docs/dev/android-tv`. Правило целиком: документация описывает только свой
продукт, а про соседний — ровно столько, сколько нужно для решений в этом
(`CONVENTIONS.md`, раздел «Документация»).

## С чего начинать

Два первых файла читаются до первой правки, остальные — по надобности.

| Файл               | Отвечает на вопрос                                              |
| ------------------ | --------------------------------------------------------------- |
| `CONVENTIONS.md`   | правила кода и документации                                      |
| `ARCHITECTURE.md`  | как устроено приложение целиком: слои, мост, оболочка, экраны   |
| `STORAGE.md`       | где лежат данные, как работают снимок, выгрузка, облако и датасет |

Описание самого продукта — что умеет, чего не умеет, как собрать
и выпустить — в `README.md` в корне репозитория.

## Чего здесь не ищите

Перевод по словарю, шапка юзерскрипта, выкладка на Greasy Fork,
блокировщик рекламы, встраивание в чужую разметку и манга — не часть
этого продукта.

## Наследство в коде

Правил перевода глав и томов и ключей чужой читалки в ядре больше нет:
они убраны вместе с мангой.

Что осталось от юзерскрипта — три ключа в `core/settings.ts`:
перевод интерфейса (`set_interface`), блокировка всплывающих окон
и рекламы. Ключи читаются при загрузке настроек, но что именно из них
на что влияет в окне — сверяется по коду.

Ссылки на сторонние каталоги с нелицензионным содержимым
(`set_link_rutracker`, `set_link_yummy`, `set_link_animego` и домены
к ним) убраны вместе с самим кодом ссылок: карточка тайтла даёт
только AniList, MyAnimeList, Шикимори и страницу источника описания —
см. `media-links.ts`. Ушло и `set_extlinks`: внешними ссылками
управлять было нечем, ключ ничего не включал. Ключи, оставшиеся в
файлах настроек у прежних пользователей, просто перестали читаться.
