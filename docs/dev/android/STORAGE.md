# Хранение приложения Android

## Пользовательские данные

Список, настройки и история активности хранятся локально. AniList, Shikimori и XML MyAnimeList используются как источники импорта. AniList и Shikimori используются как источники импорта; локальные правки сохраняются на устройстве.

## Настройки и снимок

`core/settings.ts` читает и записывает ключи через `Bridge.storage`. Последовательность записи обеспечивает `core/store-chain.ts`.

`core/snapshot.ts` сохраняет список и связанные пользовательские поля под ключом `AM_SNAPSHOT`. Файловый дубль `animori-snapshot.json` записывается оболочкой в приватный каталог через белый список `src-tauri/src/files.rs`. Склад сетевых ответов и датасет в снимок не входят.

Снимок содержит названия AniList, идентификаторы, статусы, оценки, эпизоды, даты и заметки. Русские названия и позиции просмотра хранятся отдельно.

## Кэш и датасет

`core/db.ts` хранит ответы API в IndexedDB с типами срока действия из `core/cache-life.ts`. `core/dataset-names.ts` загружает сжатые файлы `animori-data`: `index.json`, `titles-anime.json.gz` и `map-mal-anilist.json.gz`. Проверяются версия и SHA-256; распакованный файл хранится как `animori-dataset.json`.

При разрешении названия используются память текущего запуска, датасет, IndexedDB и сетевой API. Источник русских названий в рантайме — Shikimori; датасет снижает число сетевых запросов.

## Импорт, экспорт и облако

Импорт реализован в `core/collection.ts`, `core/mal-xml.ts` и API-модулях AniList/Shikimori. XML формата MyAnimeList формируется в `core/mal-xml.ts`; импорт разбирается в `api/mal-import.ts`.

Яндекс Диск подключается через `src-tauri/src/cloud.rs`. Токен хранится в зашифрованном хранилище, а копия списка передаётся только по действию пользователя.

## Секреты

AniList token, токен Яндекс Диска и пароль прокси шифруются Android Keystore. Доступ к значениям имеют `src-tauri/src/secrets.rs` и Kotlin-плагин; WebView получает только статусы и результаты операций.
