# Линт и форматирование

ESLint проверяет исходники TypeScript, Vue и JavaScript-модули. Prettier форматирует исходники и Markdown. Конфигурация ESLint отключает конфликтующие правила форматирования через `eslint-config-prettier`.

Конфигурационные файлы: `.prettierrc.mjs`, `eslint.config.mjs` и `.prettierignore`.
